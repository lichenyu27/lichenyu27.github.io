ESP32 按钮控制台

点按钮 → 发请求 → 板子动起来

发送方式

按钮清单 0

    还没有按钮，点右上角「＋ 新建按钮」

    小贴士

    • 布局模式下拖动按钮即可改位置，松手自动保存。
    • 运行模式下长按 0.4 秒也能拖动。
    • 双击按钮可打开属性面板改名字 / 颜色 / 地址。
    • 所有配置存在浏览器本地（localStorage），换设备请用「导出 / 导入」。
    模式：自动 0 个按钮 页面：http
    🎛️
