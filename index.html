导入题库

🔑 检测到本机已保存 GitHub 令牌，是否使用它？（仅用于访问私有库或提升额度，公开库无需令牌）

按 GitHub 用户名 / 组织名（owner）访问：列出该账号下的仓库，进入目录后选择题库 JSON 即可答题。填令牌可包含私有仓库，公开仓库不填令牌也能浏览。

或直接填 owner/repo 快速读取（公开库免令牌 · 支持分享链接）

也支持分享链接 ?repo=owner/repo 直接打开并加载题库。

选择一个 .json 题库文件上传。

把题库 JSON 直接粘贴到下方文本框。

🤖 AI 生成题库提示

不会写 JSON？把下面这段提示词复制给 DeepSeek / ChatGPT 等 AI，让它按格式生成题库，再把生成的 JSON 用本页「本地文件」或「GitHub」方式导入即可。

【答题小站 · 题库格式】
题库是如下结构的 JSON：
{
  "title": "题库标题",
  "questions": [
    {
      "type": "single",            // 单选题
      "question": "题干文字",
      "options": ["选项A","选项B","选项C","选项D"],
      "answer": 0,                 // 正确选项下标（从 0 开始）
      "explanation": "解析（可选）"
    },
    {
      "type": "multiple",          // 多选题
      "question": "题干文字",
      "options": ["A","B","C","D"],
      "answer": [0,2],             // 正确选项下标数组
      "explanation": "解析（可选）"
    },
    {
      "type": "boolean",           // 判断题
      "question": "题干文字",
      "answer": true,              // true=正确, false=错误
      "explanation": "解析（可选）"
    }
  ]
}

【给 AI 的指令（复制发给 AI）】
请根据《课程名称》出 N 道练习题，涵盖单选、多选、判断三类，严格按上面的 JSON 格式输出，只输出 JSON，不要任何额外说明。

📐 题库 JSON 格式说明 
{
  "title": "示例题库",
  "questions": [
    { "type": "single",   "question": "单选题干", "options": ["A","B","C","D"], "answer": 0, "explanation": "可选" },
    { "type": "multiple", "question": "多选题干", "options": ["A","B","C"],    "answer": [0,2], "explanation": "可选" },
    { "type": "boolean",  "question": "判断题干", "answer": true, "explanation": "可选" }
  ]
}
  • type：single（单选）/ multiple（多选）/ boolean（判断）
  • answer：单选为正确选项下标（从 0）；多选取正确下标数组；判断为 true/false
  • 容错：answer 也支持 "A"、"对"、"true" 等文本，会自动归一化
  • 判断题可省略 options，自动渲染「正确 / 错误」
